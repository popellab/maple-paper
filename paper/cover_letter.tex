\noindent Dear Editors,

We submit ``Structured Schemas for LLM-Modeler Collaboration in Quantitative Systems Pharmacology Model Calibration'' for consideration as an Article in CPT: Pharmacometrics \& Systems Pharmacology.

QSP model calibration requires integrating quantitative data from diverse published sources, yet this process remains manual and poorly documented. Large language models can accelerate extraction but can introduce hallucination and fabrication errors unacceptable for quantitative modeling. We present MAPLE, a framework that uses structured validation schemas as a collaboration interface between LLMs and modelers, catching characteristic errors while preserving full provenance. We evaluate the framework on 87 calibration targets for a pancreatic ductal adenocarcinoma QSP model.

Both the framework (\url{https://github.com/popellab/maple}) and all extraction data (\url{https://github.com/popellab/maple-paper}) are publicly available. This manuscript has not been published elsewhere and is not under consideration by another journal.

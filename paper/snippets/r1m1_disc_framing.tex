The curation results show where modeler input enters the workflow. The LLM produces competent forward-model choices and observable code when it has enough context, but cannot recognize when context is missing, and can also miss inputs or lose track of constraints across long records. Modeler curation closes the resulting gaps: for batch-extracted SubmodelTargets, forward-model type changed in \smtFmTypeChangedPct{} of files, prior distributions in \smtPriorChangedPct{}, input data values in \smtInputsChangedPct{}, and source-relevance assessments in every file; for CalibrationTargets, observable code in \ctObsCodeChangedPct{} of batch-extracted files, species lists in \ctSpeciesChangedPct{}, and empirical data in \ctEmpiricalChangedPct{}. Missing context typically involves unit conventions the LLM cannot infer from the model definition (for example, the Abercrombie 3D-to-2D correction used to convert section-level cell counts to volumetric densities) and source-applicability decisions that require recognizing marker-definition mismatches (e.g., a study reporting CD86+ as an M1 marker mismatched to the simulation's M1/M2 categorization). Section~\ref{sec:curation-categories} describes the full taxonomy. Interactive extraction reduces these revisions by letting the modeler supply context as gaps surface. The modeler's review of every record also catches the LLM lapses the validators do not detect, which is why paired human review remains part of the workflow even with full validator coverage. The framework makes the context dependency auditable: every claim in the YAML carries both a source reference and a verbatim snippet, with cross-species or cross-indication uses additionally requiring a documented justification (Supplementary Section~\ref{sec:collaboration-modes}).
